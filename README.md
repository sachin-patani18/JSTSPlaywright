# JSTSPlaywright

A learning workspace for JavaScript fundamentals, test automation, and QA prompt engineering.

- `01_chapter_JS_Basics/` — introductory JavaScript examples.
- `02_Chapter_JS_Keyword_ldentifire/` — JavaScript engine, keywords, identifiers, naming conventions, and comments.
- `00_chapter_prompt_Eng/` — RICE-POT prompt-engineering references, a Selenium automation framework, and a Salesforce login test plan. See its [README](00_chapter_prompt_Eng/README.md) for details.
